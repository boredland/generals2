# generals2

Open-source recreation of the cancelled *Command & Conquer: Generals 2*. Not affiliated with or endorsed by EA. All trademarks are the property of their respective owners. `vendor/` contains GPL-3.0 code; the EA release carries GPL §7 additional terms (no trademark use, no claims of EA affiliation, modifications must be marked). `archive/` bulk data is local-only and never committed or redistributed.

- `archive/` — research material (manifests committed, media/binaries gitignored), see `archive/README.md`
- `vendor/` — upstream source as git submodules, see `vendor/README.md`
- `the local field notes` — annotated index of everything archived
- `scripts/` — idempotent download/manifest scripts
